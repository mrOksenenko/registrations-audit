# Аудит файла registrations.csv

Небольшой учебный проект: критический аудит CSV-файла с регистрациями на мероприятие и правки по его итогам.

## Что внутри

| Файл | Содержимое |
|---|---|
| [PROMPT.md](PROMPT.md) | Исходный промпт, с которого всё началось |
| [AUDIT.md](AUDIT.md) | Что нашёл аудит: ошибки, риски, слабые места |
| [CHANGES.md](CHANGES.md) | Что исправили после аудита |

## Что исправили (кратко)

После аудита:

- заменили обозначения «да» и «нет» на `true` / `false`;
- заменили правописание слова «Партнёры» на «Партнеры»;
- проверили названия городов: все они уже записаны одинаково, дополнительных замен не потребовалось.

Сам файл `registrations.csv` в репозиторий не включён: в нём имена людей и статус оплаты.
